E-Commerce Backend Application

A production-oriented **Spring Boot e-commerce backend** implementing complete
**cart → order → payment → refund → return lifecycle** using clean architecture
and design patterns.

---

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Hibernate
- Lombok
- REST APIs
- Strategy Design Pattern
- UUID-based User IDs

---

## Key Design Principles
- Separation of concerns
- Strategy Pattern for Payment & Refund
- Transactional consistency
- Clear order lifecycle management
- Scalable for microservices & Kafka later

---

# USER FLOW

## 1️⃣ User & Address
- User registers (UUID generated)
- User can add multiple addresses

POST /users
POST /users/{userId}/address
GET /users/{userId}/address

-----------------------------------------------------------------------------------------------------------

## 2️⃣ Product Browsing
- View all available products

GET /products

--------------------------------------------------------------------------------------------------------------

## 3️⃣ Cart Management
- Add product to cart
- Update quantity
- Remove product
- View cart

POST /cart/{userId}/add
PUT /cart/{userId}/item/{itemId}
DELETE /cart/{userId}/remove/{productId}
GET /cart/{userId}

--------------------------------------------------------------------------------------------------------------

## 4️⃣ Checkout (Order Creation)
- Cart converted into Order
- Stock validated & reserved
- Cart cleared

POST /orders/{userId}/checkout

**Result**
OrderStatus = PLACED

-----------------------------------------------------------------------------------------------------------

## 5️⃣ Payment (Strategy Pattern)

### ONLINE
PLACED → PAID

### CASH ON DELIVERY (COD)
PLACED → CONFIRMED

PUT /payment/{orderId}/pay/{userId}

json:
{
  "paymentMode": "ONLINE | COD",
  "success": true
}

-----------------------------------------------------------------------------------------------------------

6️⃣ Order Lifecycle
ONLINE
PLACED → PAID → CONFIRMED → SHIPPED → DELIVERED

COD
PLACED → CONFIRMED → SHIPPED → DELIVERED → PAID
---------------------
7️⃣ Order History
GET /orders/{userId}
-------------------------
8️⃣ Cancel Order (Before Delivery)
Rules
Status	          Cancel	          Refund
CONFIRMED (COD) 	✅	               ❌
PAID	            ✅	               ✅
SHIPPED	            ❌	               ❌
DELIVERED	        ❌	               ❌
PUT /orders/{orderId}/cancel/{userId}
-----------------------------------------------------
9️⃣ Return Order (After Delivery – Planned)
DELIVERED
 ↓
RETURN_REQUESTED ( PUT /return/{orderId}/return/{userId} )
 ↓
RETURN_APPROVED ( PUT /return/admin/{orderId}/return/approve )
 ↓
BANK_DETAILS_SUBMITTED (COD) ( PUT /refund/{orderId}/bank-details/{userId} )
 ↓
REFUND_INITIATED
 ↓
REFUNDED ( GET /refund/{orderId} )
-------------------------------------------------------------------------
